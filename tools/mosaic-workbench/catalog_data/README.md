# Catalog contract

`adapter-contract.json` pins the audited source constructor translations to the included Library bundle hash. Unknown expressions remain evidence rather than executable code. A changed Library bundle may require an explicit adapter update.

The current included release exposes 55 components and 464 selectable entries; Image cards has 49 variants in 13 size families. Availability is not visual acceptance. Use `doctor.py` to verify the actual checked-out package.
